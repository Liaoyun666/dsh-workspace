# QQ 版大肥鱼：本机从零跑通笔记（Windows，无管理员权限）

日期：2026-10-29。目标：AstrBot + NapCat + 大肥鱼配置包。
全程不需要管理员权限的部分都跑通了；**只剩 QQ 扫码**（那一步要管理员 + 人工扫码）。

---

## 0. 为什么不用系统 Python

本机系统 Python 是 3.10.0rc2 + pip 21.2.3，装 AstrBot 会卡死（触发 pip-build-tracker 源构建）。
改成：独立 CPython 3.12.16（python-build-standalone）+ uv 装包，几十秒完成。

```bash
# 1) 独立 Python 3.12（21 MB）
curl -L -o py312.tar.gz "https://github.com/astral-sh/python-build-standalone/releases/download/20261026/cpython-3.12.16%2B20261026-x86_64-pc-windows-msvc-install_only_stripped.tar.gz"
mkdir -p "$LOCALAPPDATA/py312" && tar -xzf py312.tar.gz -C "$LOCALAPPDATA/py312" --strip-components=1
"$LOCALAPPDATA/py312/python.exe" --version   # Python 3.12.16

# 2) uv（15 MB）
curl -L -o uv.zip "https://github.com/astral-sh/uv/releases/latest/download/uv-x86_64-pc-windows-msvc.zip"
# 解压出 uv.exe

# 3) venv + AstrBot（走清华源）
export UV_DEFAULT_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple
export UV_PYTHON_DOWNLOADS=never     # uv 自带的 python 下载器连 github release 会超时
uv venv astrbot-venv312 --python "$LOCALAPPDATA/py312/python.exe"
uv pip install --python ./astrbot-venv312/Scripts/python.exe astrbot
```

> 坑：`uv python install 3.12` 会卡在 `client error (Connect) ... operation timed out`
> （连不上 github release），所以 python 只能自己 curl 下来解压，再用 `--python` 指过去。

## 1. 启动 AstrBot

```bash
cd astrbot-home
../astrbot-venv312/Scripts/astrbot.exe run -p 6185 > ../astrbot-run.log 2>&1
```

- 后台：http://127.0.0.1:6185 ，用户名 `astrbot`，初始密码在第一次启动的日志里（`astrbot-run.log`）。
- 数据都在 `astrbot-home/data/`。

## 2. 配置 OneBot v11（给 NapCat 反连）

`astrbot-home/data/cmd_config.json` **带 UTF-8 BOM**，Python 读写必须 `encoding='utf-8-sig'`，否则
`json.decoder.JSONDecodeError: Unexpected UTF-8 BOM`。

用 `set_platform.py` 写入（会自己备份 `cmd_config.json.bak-before-platform`）：

```json
"platform": [{
  "id": "default",
  "type": "aiocqhttp",
  "enable": true,
  "ws_reverse_host": "0.0.0.0",
  "ws_reverse_port": 6199,
  "ws_reverse_token": ""
}]
```

重启后 `netstat -ano | grep 6199` 应能看到监听。

## 3. NapCat（这一关卡住了）

用 `NapCat.Shell.Windows.OneKey.zip`（NapCatQQ v4.18.41）：解压后跑 `NapCatInstaller.exe`，
它会自动下 QQ 9.9.33（300 MB）和 NapCat.Shell.zip（34 MB，走镜像），生成 `NapCat.52230.Shell\`。

**问题**：安装器要管理员权限才能把 QQ 装进系统，没有权限时 QQ 只是躺在 Shell 目录里：

| 尝试 | 结果 |
| --- | --- |
| 直接跑 `NapCat.52230.Shell\QQ.exe` | `config_current_version:9.9.33-52230 ... error code v2:-8` 后退出 |
| Shell 根目录 `NapCatWinBootMain.exe`（老版） | 只打印 `Usage: ... <quickLogin>` |
| `app\napcat\NapCatWinBootMain.exe <QQPath> <HookDll>` | 正确用法，但**要管理员**，非提权启动无输出即退 |
| `launcher.bat` | 查注册表 `HKLM\...\Uninstall\QQ` 找 QQ，没装系统版 → "QQ installation was not found in the registry" |

结论：**必须以管理员身份**启动
```
app\napcat\NapCatWinBootMain.exe "<Shell>\QQ.exe" "<Shell>\versions\9.9.33-52230\resources\app\napcat\NapCatWinBootHook.dll"
```
并设好这几个环境变量（launcher.bat 里的原值）：
`NAPCAT_PATCH_PACKAGE=qqnt.json`、`NAPCAT_LOAD_PATH=loadNapCat.js`、
`NAPCAT_INJECT_PATH=NapCatWinBootHook.dll`、`NAPCAT_LAUNCHER_PATH=NapCatWinBootMain.exe`、`NAPCAT_MAIN_PATH=napcat.mjs`。

`启动NapCat后台.bat` 就是干这个的（`Start-Process -Verb RunAs` 提权）。
本机这台没弹 UAC 也没起来，**换一台能拿到管理员的机器跑**最省事。

登录后：
- NapCat WebUI：http://127.0.0.1:6099
- 或直接改 `app\napcat\config\onebot11_<QQ号>.json`，加一个反连 WS：
  `"ws-reverse": {"enable": true, "url": "ws://127.0.0.1:6199/ws"}`
- AstrBot 后台看到机器人在线即可。

## 4. 导入大肥鱼人格

```bash
cd dafeiyu-config-pack
# 回答文件：base_url / username / password / owner_qq / memory / voice
../astrbot-venv312/Scripts/python.exe -X utf8 tools/import_dafeiyu.py --answers 回答.json
```

- 会先登录后台；**后台没有 OneBot 机器人时会停住**：
  `后台里还没有 QQ 机器人（OneBot v11），先按视频接好 NapCat 再来。`
- 所以顺序必须是：NapCat 登录 → AstrBot 见到机器人 → 再跑导入。
- 别双击 `导入大肥鱼.bat`（一问一答会卡在「按任意键」），用上面的 `--answers`。
