# 大肥鱼唤醒窗口

群聊里 AstrBot 默认只在被 @ 时唤醒，所以不 @ 就不说话。装了这个插件之后：

1. 你在群里 @ 一次大肥鱼 → 给它开一个窗口（默认 **180 秒**）；
2. 窗口期内，**你**在**同一个群**发的消息，即使不 @，也会被当成在跟它说话并得到回复；
3. 窗口到期自动失效，回到「只有 @ 才回」。

## 配置

| 键 | 说明 | 默认 |
|---|---|---|
| window_seconds | 窗口时长（秒），10~3600 | 180 |
| groups | 只对这些群生效，留空=全部群 | [] |
| extend_on_message | 窗口内每说一句就续期 | false |
| sleep_start | 睡眠开始的小时（这个点之后不主动接话） | 0 |
| sleep_end | 睡眠结束的小时 | 8 |

睡眠时段内：**不随机接话**，但有人 @ 本鱼、或窗口还开着，照样会回。要彻底静默就把 ambient_enable 关掉。

## 分段规矩（v1.2）

- **一句一条**：她自己打的换行、句号、问号、感叹号就是断点，一句一条发出去，不把两句挤在一条里。
- **绝不瞎断**：逗号、顿号、省略号都不算断点；一句太长（超 split_max_chars，默认 80 字）才在逗号后面补救着切。
- **节奏**：短句快发，长句稍微停一下，间隔 1.0–2.8 秒（split_delay_min/max）。
- **条数**：最多 split_max 条（默认 8），超出的并进最后一条，不丢字。

## 按热闹程度自动调概率（v1.3）

- 插件自己数群消息：最近 `ambient_activity_window` 秒（默认 600）里，群里非本鱼的消息有多少条。
- 插话概率在这个条数上插值：冷清时 = `ambient_probability`（默认 0.08），
  达到 `ambient_activity_full` 条（默认 20）时 = `ambient_probability_max`（默认 0.35）。
- 曲线用 0.7 次方，所以中等热闹（10 分钟十来条）就已经明显比冷清时爱插嘴：
  0 条 0.08 / 3 条 0.15 / 5 条 0.18 / 10 条 0.25 / 15 条 0.30 / 20 条以上 0.35。
- 每次真的开口都会在日志里写下当时的条数与概率：
  `随机接话：群 xxx …（10 分钟内 N 条，本次概率 0.21）`，方便回头看是不是太吵。
- 冷却（`ambient_cooldown`）和睡眠时段照旧优先，热度只影响「轮到她的时候掷不掷得中」。

## 配合

- 群聊里如果还有别的「概率插话」插件会抢消息（例如 group_chat_plus 的 enable_group_chat），
  它们会把 event.call_llm 置 True 导致默认回复被吞掉；用这套功能时把它们关掉。
- 私聊本来就不需要 @，这个插件不管私聊。
