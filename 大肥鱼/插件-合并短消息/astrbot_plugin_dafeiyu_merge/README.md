# 大肥鱼消息合并（astrbot_plugin_dafeiyu_merge）

主人连着发「你」「是」「看」「一」「句」……一条条蹦的时候，她原来会一条条懵着接
（「就一个「你」」「我是不是该请安」「你一句话掰成好几段发」）。
这个插件在流水线最前面拦一下：同一个会话里连续到达的短消息先攒着，
等对方停手 \`debounce_seconds\` 秒，合成一句话再交给模型——只触发一次、只回一次，
而且她看到的是完整句子。

## 怎么攒的

- 只处理「本来就会让她回话」的消息：私聊，或群里 @ 她 / 用唤醒词叫她；
  群里没叫她的闲聊走唤醒窗口那套，这里不掺和。
- 指令（原文以 \`/\`、\`!\`、\`#\` 开头）不攒，直接交给后面的处理器。
- 同一个会话（umo + 发送者）一个缓冲，两条消息间隔超过 \`reset_after_seconds\`（默认 15 秒）就重新算一条。

## 怎么合的

- 每条都只有一两个字（≤ \`direct_chars\`，默认 2）→ 直接粘起来：
  \`你/是/看/一/句/回/一/句/吗\` → \`你是看一句回一句吗\`
- 有长有短 → 一句一行（她的人设本来就是一句一条）：
  \`在吗\` + \`帮我查下天气\` → 两行
- 上一段以逗号/顿号收尾 → 同一行接下去。

## 配置（\`data/config/astrbot_plugin_dafeiyu_merge_config.json\`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| enabled | true | 总开关 |
| debounce_seconds | 1.0 | 最后一条之后等多久再合并 |
| reset_after_seconds | 15 | 隔多久就不算同一句 |
| max_parts | 12 | 最多攒几条（多的丢最老的） |
| merge_private | true | 私聊合并 |
| merge_group | true | 群里被叫到时合并 |
| direct_chars | 2 | 每段不超过这个字数就直接粘成一句 |

## 实现（占位等待，不重注入队列）

1. handler 用 \`priority=100\` 抢在所有插件前面；
2. 每条消息记进缓冲区后 \`await asyncio.sleep(debounce)\`；
3. 醒来发现缓冲区里已经有更晚的片段（\`seq\` 变了）→ \`event.stop_event()\` 让位，这条不回；
4. 最后一条醒来发现没新片段 → 把 \`event.message_str\` 改成合并文本，继续走完整流程 → 只回一次。
