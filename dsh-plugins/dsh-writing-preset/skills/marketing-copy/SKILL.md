# 营销与品牌文案

## 先问清三件事

1. **给谁看**：具体到人群、场景、痛点，而不是「年轻人」「企业客户」。
2. **要什么行动**：点击、留资、购买、转发、记住品牌？只保留一个主行动。
3. **凭什么相信**：可验证的事实、数据、案例、资质、用户评价。

没有这三项就先补齐；补不齐时，按最合理的假设写，并在交付时注明假设。

## 结构：一个卖点，一条证据链

```
洞察（读者的真实处境）
  → 承诺（用了会得到什么，具体可感）
  → 证据（数据 / 案例 / 对比 / 第三方背书）
  → 行动（下一步做什么，门槛多低）
```

- 一篇文案只讲一个核心卖点。其余卖点降为支撑句。
- 承诺必须可验证，避免「行业领先」「颠覆式创新」这类无法证伪的说法。
- 证据优先用具体数字与场景对比：「3 分钟出报告」优于「高效便捷」。

## 标题与开头

可选结构（每次给 3–5 个候选）：

- 数字 + 结果：「3 个模板，把周报时间从 2 小时压到 20 分钟」
- 冲突 / 反常识：「越努力越穷？问题可能出在记账方式」
- 具体场景 + 痛点：「开会两小时，结论一句话——问题不在会议」
- 提问 + 共鸣：「为什么你写的方案总在第二页被否？」
- 直接利益：「明天起，报价单自动生成」

开头 3 句内完成：制造相关性 → 点出痛点 → 给出承诺。不要在开头铺垫行业大势。

## 调性与渠道

| 渠道 | 语气 | 长度 | 注意 |
|---|---|---|---|
| 公众号 | 有观点、可读性优先 | 1500–3000 字 | 开头 3 行决定打开率，结尾给行动 |
| 社媒短文案 | 口语、有情绪 | 50–300 字 | 一句话一个意思，标签不超过 3 个 |
| 产品落地页 | 克制、信息密度高 | 分区块 | 每个区块一个卖点 + 一个证据 |
| 广告语 / slogan | 押韵或对仗 | 6–16 字 | 可读、可记、可传播，避免生造词 |
| 活动方案 | 清晰、可执行 | 视需求 | 目标、机制、预算、风险分开写 |

## 多版本交付

- 默认给 2–3 个方向（稳健版 / 锐利版 / 情感版），说明各自适合的场景。
- 每个版本标注：核心卖点、目标人群、预计语气、风险点。
- 不自作主张选一个「最好的」；让用户选，或说明你的推荐及理由。

## 常见问题

- 形容词堆砌：「高端、专业、贴心、高效」——换成可验证的事实；
- 自嗨式开场：「在这个快速变化的时代……」——直接进入读者处境；
- 卖点过多，读者一个也记不住；
- 行动号召模糊：「欢迎了解」——改成「点击领取」「回复关键词获取」；
- 承诺越界：效果、收益、疗效类表述需符合广告法与平台规则，拿不准就加限定条件。
