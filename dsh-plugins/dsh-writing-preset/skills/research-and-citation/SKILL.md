# 调研取证与引注

## 来源分级

| 级别 | 来源 | 用法 |
|---|---|---|
| A | 官方文件、原始数据、一手访谈、同行评审论文 | 可直接引用并作为结论依据 |
| B | 主流媒体的事实报道、行业机构报告、公司年报 | 可引用，尽量找到其原始出处 |
| C | 二手转载、百科、自媒体、营销稿 | 只作为线索，不作为唯一依据 |
| D | 匿名帖、截图、无法追溯的「据说」 | 不写进正文 |

## 检索步骤

1. 把论点拆成可检索的问题（谁、何时、多少、依据什么）。
2. 先找一手来源：官网公告、统计年鉴、监管文件、论文原文。
3. 用不同关键词与语言交叉搜索，至少两个独立来源互相印证。
4. 核对时间：引用的是最新版本还是已被修订的旧版。
5. 保存链接、标题、发布时间、关键原文句，写进事实卡；链接可能失效，关键内容要摘录。

## 事实卡格式

```
结论：2025 年中国新能源汽车销量约 X 万辆
来源：中国汽车工业协会《2025 年汽车工业经济运行情况》
链接：https://…
时间：2026-01-15
原文：「……」
可信度：高（A 级，官方统计，与乘联会数据互相印证）
```

正文中每个关键数字与引语都应能对应到一张事实卡。

## 引注规范

- **正文标注**：数字或引语后紧跟来源，如「（中汽协，2026）」；不要只在文末罗列。
- **参考列表**：按出现顺序编号，格式统一。中文常用：作者. 标题[文献类型]. 出版者/网站, 年份. 链接.
- 同一来源多次引用，正文用同一编号。
- 直接引语加引号并保留原文；转述不加引号，但要忠实原意，不扩大范围。
- 图片、表格、数据图注明来源与获取时间。

## 不确定性的写法

- 单一来源：「据 X 报道（未经独立核实）……」
- 口径不明：「按 Y 口径统计……；若按 Z 口径，数字会不同。」
- 预测与估计：「研究机构预计……，该预测基于……假设。」
- 查不到：「公开资料中未找到……，以下判断基于……」
- **绝不编造**来源、数据、人物言论或链接。宁可少写，也不虚构。

## 合规与隐私

- 引用个人言论与信息时，确认公开可引用，避免泄露隐私；
- 商业数据注意授权范围，不以「转载」名义大段复制；
- 涉及医疗、金融、法律等专业结论，注明「不构成专业建议」并建议咨询专业人士。
