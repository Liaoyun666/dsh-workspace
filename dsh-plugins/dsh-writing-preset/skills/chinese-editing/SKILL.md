# 中文改稿与润色

## 原则

1. **保留作者的声音**：改病句、删冗余、理逻辑，不把文章改成你自己。除非用户要求，不重写立意与结构。
2. **不擅自改动事实**：数字、人名、时间、引语、政策原文一律以来源为准；发现可疑只标注，不静默修正。
3. **改动要可解释**：重要修改给出理由，让作者能判断是否接受。
4. **分层处理**：先结构与事实，再句子，最后字词与标点；不要一边读一边零散改词。

## 检查清单

### 事实层

- 数字、单位、百分比、时间、人名、机构名、头衔是否与来源一致；
- 引语是否为原话，转述是否歪曲语气与范围；
- 政策、法规、标准是否引用了现行版本，生效日期是否正确；
- 因果关系是否被写成相关关系（「因为 A 所以 B」是否有证据）。

### 结构层

- 每段是否有且只有一个中心？中心句是否在段首或段尾显眼位置；
- 段落顺序是否递进：背景 → 问题 → 分析 → 方案 → 结论；
- 有没有该合并的短段、该拆开的长段；
- 开头是否交代「为什么值得读」，结尾是否回扣目的与行动。

### 逻辑层

- 论据是否真的支撑论点，还是只是相关；
- 有没有循环论证、以偏概全、滑坡、稻草人；
- 「因此 / 所以 / 这意味着」前后的推理是否成立；
- 反例与边界条件是否交代。

### 语气与文体层

- 与目标读者、场合匹配：公文不口语，社媒不端架子；
- 主语一致，避免「我们 / 你 / 本文」混用；
- 少用「非常、极其、十分、大力、全面、深入」等空泛程度词；
- 删掉「值得注意的是、众所周知、毋庸置疑、可以说」等填充语；
- 中文优先用短句；一句话里超过两个逗号就考虑拆句。

### 字词与标点层

- 错别字与同音字：的 / 地 / 得、在 / 再、做 / 作、即 / 既、以至 / 以致；
- 「的的不休」：连续三个以上的「的」通常可以删；
- 翻译腔：被字句滥用、「进行 + 名词」、「对于……而言」、「不仅……而且……」堆叠；
- 伪高级词：赋能、抓手、闭环、底层逻辑——除非受众确实使用，否则换成具体说法；
- 中文标点：句号「。」、逗号「，」、顿号「、」、引号「“”」、破折号「——」；不用英文标点混排；
- 数字：同篇统一（中文数字或阿拉伯数字），百分比与单位前后一致；
- 空格与排版：中文与英文、数字之间可留半角空格，但不强求；全篇统一即可。

## 压缩篇幅

用户要求「精简」时，按以下顺序删：

1. 与目的无关的段落；
2. 重复表达同一意思的句子；
3. 空泛的形容词、程度副词、套话；
4. 可以用一个短句替代的长定语从句；
5. 过渡性的废话（「接下来我们来看看」）。

压缩后检查：论点、证据、限定条件是否都还在。

## 输出方式

- **小改动**：直接给修改后的全文，或「原文 → 修改后 → 理由」表格；
- **大改动**：先给修改说明（结构上动了什么、为什么），再给全文；
- **不确定处**：用引用块标出并说明疑点，不要替作者决定；
- 若用户只要建议，就只给建议，不要擅自重写全文。

## 前后对照示例

| 原文 | 问题 | 修改 |
|---|---|---|
| 通过对于用户需求的深入分析，我们进行了产品的全面优化与升级。 | 翻译腔、空泛、无信息 | 分析用户反馈后，我们把首页加载时间从 3 秒降到 1 秒。 |
| 这个方案的效果是非常显著的。 | 无证据的程度断言 | 这个方案让转化率提高了 12%（见附录 A）。 |
| 值得注意的是，该政策对企业的影响是深远的。 | 填充语 + 空泛 | 该政策要求企业在 2027 年前完成改造，中型企业平均成本约 80 万元。 |
