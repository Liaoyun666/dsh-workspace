# STYLE.md — 大肥鱼出片规范（一页看完，照做就行）

> 这是「美术标准」，不是「灵感建议」。任何一条视频都按这一页来，
> 想改配色/字号先改这一页，再改 toolkit/sub.py 里的 STYLE 表，别各写各的。
>
> 代码里能直接用的：`import sub`（字幕/标题卡）、`import fx`（动效）、
> `import encode`（编码）、`import voice`（配音）。
> 最小可用模板：`toolkit/demo.py`（改台词就是一条新片）。

## 1. 画幅与时长

| 项 | 值 | 说明 |
| --- | --- | --- |
| 画幅 | 720x1280（竖屏，默认）或 1080x1920 | 9:16，B 站竖屏和手机都吃这个 |
| 帧率 | 24 fps | 逐帧渲染最省时间，观感也够 |
| 时长 | 30~180 秒，默认 40~90 秒 | 短于 30 秒做不出信息量，太长没人看完 |
| 音频 | AAC 48kHz 128k，响度 **-16 LUFS**（峰值 -1.5 dBTP） | `encode.py` 已用 loudnorm 固定 |
| 视频 | H.264 yuv420p + `-movflags +faststart` | 不转 yuv420p 手机端会黑屏 |

## 2. 配色（只允许这 4 个 + 黑/白）

| 名字 | 色值 | 用在哪 |
| --- | --- | --- |
| 墨底 `bg` | `#0E1116` | 背景、描边、字幕底衬 |
| 主字 `ink` | `#F2F5F7` | 正文、标题、字幕默认色 |
| 强调 `gold` | `#FFD166` | 重点词、片头副标题、徽章底 |
| 次强调 `cyan` | `#4CC9F0` | 进度条、竖线、水印/@ |

规则：一屏里 `gold` 只强调**一个**点，`cyan` 只做**结构**（线/条/角标）不做文字填充。
深浅渐变用 `sub.bg_image()`（自带极淡颗粒，压住 8bit 色带）。

## 3. 字号层级（720x1280 基准；1080p 全部 × 1.5）

| 角色 | 字体 | 字号 | 用在哪 |
| --- | --- | --- | --- |
| 大标题 `title` | msyhbd（加粗雅黑） | 92 | 片头/章节卡，最多 2 行 |
| 二级标题 `h2` | msyhbd | 62 | 段落标题 |
| 正文 `body` | msyh | 46 | 信息卡、要点 |
| 字幕 `sub` | msyhbd | 52 | 底部字幕（超 2 行自动缩到 30 以下就截断改写） |
| 角标 `badge` | msyhbd | 38 | 左上角 EP.01 / 章节号 |
| 水印 `footer` | msyh | 32 | 右下角 @或一句尾巴 |

## 4. 安全边距与版式

- 左右安全边距 **56px**（1080p 84px）；字幕离底 **210px**，底部那 210px 只放字幕。
- 左上角角标贴安全区，不压人像眼睛/文字。
- 底部信息多的时候先加 `fx.bottom_scrim()` 压暗再写字，别在亮背景上直接白字。
- 一屏最多 3 个视觉元素：标题区 / 中部信息 / 底部字幕。再加就乱。

## 5. 字幕规则

- **必须和中文字幕**（一个视频没字幕，完播率立刻掉）。
- 一句一行，最多两行；标点去掉（句末「。」不显示，逗号可用空格代替）。
- 逐句时间来自 `voice.synthesize()` 返回的 cues（毫秒），别自己估。
- 重点词用 `emphasis=True`（金色）强调，**一句里只强调一处**。

## 6. 片头片尾模板

```
片头（0~2 秒）：bg_image + title_card(大标题, 副标题, badge="EP.01")
                + 打字机出现（fx.typewriter cps=7~10）
                + 0.3 秒淡入
正片：每 3~6 秒换一个镜头/信息卡，底部字幕跟着配音走，
      角标显示章节号 fx.chapter_badge()，底部 fx.progress_bar() 全程显示进度
片尾（最后 3~5 秒）：回到标题卡 + 一句互动（"你遇到过吗？评论区说说"）
                 + 0.45 秒淡出
```

## 7. 节奏建议（完播率导向）

1. **0~3 秒必须给钩子**：疑问句、反常识结论、或一个强画面。不要「大家好我是…」开场（demo 里那句只是自检占位）。
2. **中段保持信息密度**：每 3~6 秒一个新信息点（换画面、换字幕、换角标），不留超过 2 秒的空镜。
3. **每 15~20 秒一个小高潮**：反转、金句、或者画面突然变（推镜/抖动/擦除转场）。
4. **结尾要互动**：提问 / 求关注 / 预告下一条，别「以上就是全部内容」。
5. 语速：默认 `rate="+8%"`，口播类可到 `+15%`；别超过 `+20%`，会听不清。

## 8. 质量红线（不合格就重做）

- 没声音、没字幕、时长 < 30 秒、分辨率不是竖屏 → 不合格。
- 字幕压到画面边缘 / 被进度条挡住 → 不合格。
- 深色画面出现明显横向色带（banding）→ 用 `sub.bg_image()` 的颗粒层。
- 响度明显忽大忽小 → 走 `encode.py` 的 loudnorm，别自己 `-af volume`。
- 一屏塞 4 个以上元素、字号不一致 → 不合格（回这一页对表）。

## 9. 怎么把工具箱接进任务

```python
import voice, sub, fx, encode

info = voice.synthesize(lines, "out/voice.mp3", rate="+8%")   # 逐句配音 + 时间对齐
cues = info["cues"]
bg = sub.bg_image()                                          # 720x1280 底
img = sub.title_card("标题", "副标题", badge="EP.01", bg=bg)  # 片头
img = sub.draw_subtitle(img, cues[0]["text"], emphasis=True)  # 底部字幕（就地画）
img = fx.progress_bar(img, 0.4)                              # 进度条
img = fx.fade(img, fx.fade_envelope(t, total))               # 淡入淡出
# 逐帧存 frames/%05d.png 之后:
ok, cmd, tail = encode.encode("frames", "out/video.mp4", audio="out/voice.mp3")
```

写好 `meta.json`：`title`（≤40 字，带钩子）、`desc`（≤200 字）、`tag`（3~5 个逗号分隔）、`lines`（逐句口播）。
